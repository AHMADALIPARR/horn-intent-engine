About

This is a pure-JavaScript reimplementation of the GDScript Horn engine for demonstration. Facts are ground atoms. Rules are Horn clauses. Queries use depth-first backward chaining with unification. Variables are prefixed with ?.

The original source lives in nlp/*.gd and runs inside Godot 4. This web demo is provided under the same AGPL-3.0 license.
